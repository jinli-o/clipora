# Clipora

轻巧好看的 Windows 剪贴板历史工具，解压即用，无需安装。

A lightweight, portable clipboard history manager for Windows.

</div>

## 功能

- 自动记录复制过的文本、图片和文件，默认保留 100 条（可调 20～500）
- `Alt + V` 呼出面板，选中即粘贴回原来的窗口
- 打开面板直接打字就是搜索
- 自动识别链接、代码、颜色值、邮箱、图片、文件
- 侧边预览长文本、大图和颜色值
- 固定常用内容，不受条数上限影响
- 纯文本粘贴，去掉网页带来的格式
- 一键暂停记录，自动跳过密码管理器的内容
- 显示内容是从哪个程序复制的
- 浅色 / 深色 / 跟随系统，6 种强调色

## 下载安装

1. 点本页上方绿色的 **Code** 按钮，选 **Download ZIP**
2. 解压到任意文件夹
3. 双击 `Clipora.exe`，程序会常驻在右下角托盘

第一次运行时如果出现"Windows 已保护你的电脑"，点 **更多信息** → **仍要运行**。这是因为程序没有数字签名，不影响使用。

系统要求：Windows 10 / 11（需要 WebView2，Windows 11 已自带）

## 文件说明

```
clipora\
├─ Clipora.exe      主程序，双击运行
├─ ui\              界面文件，可用记事本修改，重启程序后生效
├─ data\            首次运行后自动生成，保存历史记录和设置
├─ 使用说明.txt
└─ src-tauri\       程序源码，普通使用不需要
```

所有数据都保存在 `data\` 文件夹里，整个文件夹拷走就能在别的电脑上继续用。

## 快捷键

| 按键 | 作用 |
|---|---|
| `Alt + V` | 打开 / 隐藏面板（可在设置中修改） |
| `↑` `↓` | 选择 |
| `Enter` | 粘贴 |
| `Shift + Enter` | 粘贴为纯文本 |
| `Ctrl + 1`～`9` | 直接粘贴第 1～9 条 |
| `Ctrl + C` | 仅复制，不粘贴 |
| `Ctrl + P` | 固定 / 取消固定 |
| `Delete` | 删除 |
| `→` / `←` | 打开 / 关闭预览 |
| `Esc` | 清空搜索 / 关闭面板 |

## 卸载

如果开启过"开机自动启动"，先在设置里关闭。然后右键托盘图标选"退出"，删除整个文件夹即可。
