Clipora 剪贴板历史 v1.0.0
========================

【开始使用】
双击 Clipora.exe 运行，程序会常驻在右下角托盘。
按 Alt + V 打开面板，选中一条记录按回车，就会粘贴到你原来的窗口。

【文件夹说明】
Clipora.exe    主程序（剪贴板监听、快捷键、托盘）
ui\            界面文件，可以直接用记事本修改
  index.html   页面结构
  style.css    颜色、字体、圆角、动画
  app.js       交互逻辑
data\          第一次运行后自动生成
  history.json 剪贴板历史
  settings.json 设置
  images\      图片记录

【修改界面】
1. 右键托盘图标，选"退出"
2. 用记事本或 VS Code 修改 ui\ 里的文件
3. 重新双击 Clipora.exe
如果改坏了，删除 ui\ 文件夹即可恢复默认界面（程序内置了一份备用界面）。

【常用快捷键】
Alt + V          打开 / 隐藏面板（可在设置里修改）
↑ ↓              选择
Enter            粘贴
Shift + Enter    粘贴为纯文本
Ctrl + 1～9      直接粘贴第 1～9 条
Ctrl + C         仅复制，不粘贴
Ctrl + P         固定 / 取消固定
Delete           删除
→ / ←            打开 / 关闭预览
Esc              清空搜索 / 关闭面板

【迁移和备份】
整个文件夹拷到别的位置或别的电脑，历史和设置都会跟着走。
只想备份记录，复制 data\ 文件夹即可。

【卸载】
如果开启过"开机自动启动"，先在设置里关掉它，然后退出程序，删除整个文件夹。
